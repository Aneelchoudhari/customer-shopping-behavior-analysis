# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes **3,900 retail transactions** to uncover customer shopping patterns, segment behavior, and deliver data-driven business recommendations — built using **Python, SQL, and Power BI**.

---

## 📌 Business Problem

A leading retail company wants to better understand its customers' shopping behavior in order to improve sales, customer satisfaction, and long-term loyalty. Management has noticed shifts in purchasing patterns across demographics, product categories, and sales channels, and wants to know which factors — discounts, reviews, seasonality, or payment preferences — drive consumer decisions and repeat purchases.

**Overarching business question:**
> How can the company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies?

## 📊 Dataset Summary

- **Rows:** 3,900 transactions
- **Columns:** 18
- **Missing data:** 37 null values in `Review Rating`

**Key fields:**
- **Customer demographics** — Age, Gender, Location, Subscription Status
- **Purchase details** — Item Purchased, Category, Purchase Amount, Season, Size, Color
- **Shopping behavior** — Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type, Payment Method

## 🔄 Project Workflow

### 1. Data Preparation & Feature Engineering (Python)
Performed in `Customer_Shopping_Behavior_Analysis.ipynb`:
- Loaded and explored the raw dataset with `pandas` (`.info()`, `.describe()`)
- Identified and imputed 37 missing `Review Rating` values using the **median rating per product category**
- Standardized column names to snake_case for readability
- Engineered new features:
  - `age_group` — binned customer age into Young Adult / Adult / Middle-aged / Senior quartiles
  - `purchase_frequency_days` — converted categorical purchase frequency (e.g., Weekly, Monthly) into numeric day intervals
- Verified `discount_applied` and `promo_code_used` were redundant (always equal) and dropped the latter
- Connected the cleaned DataFrame to a SQL database (PostgreSQL, MySQL, or MS SQL Server) via `SQLAlchemy` for downstream analysis

### 2. Business Analysis (SQL)
`customer_behavior_sql_queries.sql` answers 10 key business questions, including:

1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent above the average purchase amount
3. Top 5 products by average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Average spend & total revenue: subscribers vs. non-subscribers
6. Top 5 products with the highest discount-usage rate
7. Customer segmentation into **New / Returning / Loyal** based on purchase history
8. Top 3 best-selling products within each category
9. Whether repeat buyers (>5 previous purchases) are more likely to subscribe
10. Revenue contribution by age group

### 3. Visualization (Power BI)
`customer_behavior_dashboard.pbix` presents an interactive dashboard connected to the SQL database, visualizing customer segments, revenue trends, product performance, and discount impact for stakeholders.

### 4. Reporting
- **`Customer Shopping Behavior Analysis.pdf`** — full written report covering methodology, SQL findings, and recommendations
- **`Customer-Shopping-Behavior-Analysis.pptx`** — stakeholder-facing presentation summarizing insights visually

## 💡 Key Business Recommendations

- **Boost subscriptions** — promote exclusive benefits to grow the subscriber base
- **Customer loyalty programs** — reward repeat buyers to convert them into the "Loyal" segment
- **Review discount policy** — balance short-term sales boosts against margin control, since some products rely heavily on discounts
- **Product positioning** — feature top-rated and best-selling products more prominently in marketing campaigns
- **Targeted marketing** — concentrate marketing spend on high-revenue age groups and express-shipping customers

## 🚀 How to Run This Project

1. **Clone the repository**
   ```bash
   git clone https://github.com/Aneelchoudhari/customer-shopping-behavior-analysis.git
   cd customer-shopping-behavior-analysis
   ```

2. **Open `Customer_Shopping_Behavior_Analysis.ipynb`**
   - Run the data import, exploration, cleaning, and feature engineering cells
   - Configure your database credentials in the connection cell (PostgreSQL, MySQL, or MS SQL Server)

3. **Load the cleaned data into SQL**
   - Create a database in your SQL engine of choice
   - Run the notebook's connection cell to push the cleaned DataFrame into the database
   - Open `customer_behavior_sql_queries.sql` and run the queries to reproduce the business-question analysis

4. **Explore the Power BI dashboard**
   - Open `customer_behavior_dashboard.pbix` in Power BI Desktop
   - Point the data source connection to your SQL database
   - Refresh to view the interactive dashboard

5. **Review the findings**
   - Read `Customer Shopping Behavior Analysis.pdf` for the full report
   - View `Customer-Shopping-Behavior-Analysis.pptx` for the stakeholder presentation summary
